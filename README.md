# 🍔 Sabor Express

Projeto desenvolvido em Python com o objetivo de praticar conceitos básicos de programação.

## 📌 Funcionalidades

- ✅ Cadastrar restaurantes
- 📋 Listar restaurantes cadastrados
- 🔄 Alternar estado do restaurante (ativo/inativo)

## 🧠 Conceitos aplicados

- Variáveis
- Estruturas condicionais (if/elif/else)
- Laços for e while
- Funções
- Listas
